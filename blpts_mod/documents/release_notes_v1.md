# BLPTS Modernized -- Release Notes v1
**Author:** K. Ibarra, Applications Developer
**Date:** 2026-04-15

## Fixed
- **Fee calculation unified.** Type C (Home Occupation) renewals now
  consistently charge $75.00, resolving the inconsistency previously
  reported (BLPTS-DISC-1) where the amount depended on which legacy code
  path processed the renewal.
- **Inspection exemption now explicitly documented.** License types C and
  E remain exempt from the 30-day inspection rule; this is now codified
  with a direct reference to Ordinance 2009-14, Section 3(b), confirmed
  via the County Clerk's Office (BLPTS-DISC-2).

## New
- **Multi-year renewal.** Businesses may now renew licenses for 1, 2, or
  3 years at once, receiving a 5% discount (2-year) or 10% discount
  (3-year) on the total. This feature has no legacy equivalent.

## Notes
This release does not modify any historical renewal records from the
legacy system. Historical fee amounts remain as originally charged.
