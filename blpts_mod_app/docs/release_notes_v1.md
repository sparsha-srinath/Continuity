# BLPTS Modernization v1 Release Notes

**Author:** K. Ibarra, Applications Developer  
**Date:** 2026-04-01

## Fee calculation

Renewal fee calculation is now unified. Type C renewals consistently charge $75.00, including the Home Occupation Plus surcharge. The legacy system could charge either $50.00 or $75.00 depending on whether the database-side or screen-side path processed the renewal; this resolves the drift documented by BLPTS-441.

## Inspection rules

The exemption for license types C and E is now explicitly documented as based on Ordinance 2009-14, Section 3(b), following confirmation from the County Clerk's Office.

## New multi-year renewal

Businesses may renew for two or three years at once. Two-year terms receive a 5% discount and three-year terms receive a 10% discount. This feature did not exist in the legacy system.
